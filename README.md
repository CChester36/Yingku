# 映库 Yingku

面向 Windows 的本地AV资料库管理软件，让整理好的影片资料拥有清晰、直观的浏览界面。

支持读取 **MDCx** 刮削结果，基础兼容 **MDC、JavSP** 的刮削结果。目前仅提供安装包，暂未公开映库源代码。

**[下载最新版本](https://github.com/CChester36/Yingku/releases/latest)** · **[查看历史版本](https://github.com/CChester36/Yingku/releases)** · **[问题反馈](https://github.com/CChester36/Yingku/issues)**

## 主要功能

- **海报墙与影片详情**：浏览影片封面，查看简介、演员、系列、标签和剧照等资料。
- **演员馆藏与系列馆藏**：集中查看关联作品，支持演员头像自定义。
- **评分与观看记录**：为影片、演员和系列评分，管理已观看与未观看状态。
- **搜索与筛选**：搜索影片、演员和标签，通过标签和星级等条件筛选馆藏。
- **首页推荐**：展示推荐影片、最近播放、最近加入和常看演员。
- **刮削结果兼容**：以 MDCx 整理结果为基础，额外提供 MDC、JavSP 的基础兼容。

## 系统要求

- Windows 10 / Windows 11
- 64 位系统（x64）

## 下载与使用

1. 前往 [最新版本下载页面](https://github.com/CChester36/Yingku/releases/latest)。
2. 在页面下方的 **Assets** 中下载 `.exe` 安装包，按照提示安装。`Source code` 压缩包不是安装程序。
3. 首次使用可前往 **设置 → 刮削器和教程** 查看资料整理与使用说明。
4. 添加已整理好的本地影片资料文件夹，扫描后即可浏览馆藏。

映库用于管理用户已有的本地媒体资料，不提供影片资源或影片下载服务。
